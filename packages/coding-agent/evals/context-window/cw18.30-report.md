## Prepared Natural Protocol

LangChain A and C free real-entry preparations completed with `paidCalls: 0`:
`.artifacts/langchain-natural-{a,c}-preflight-20260907`.
Both use the previous 128000 context configs, medium thinking, 4000 max output,
100 requests, estimated USD 2 per trial and 1800-second SDK timeout. These are
prepared settings, not a record of paid execution or sufficient-duration proof.
The outer limits can truncate a genuinely long task and must be reported as
such, not reclassified as memory loss. No automatic retries or limit increases.

The actual real command must omit `--controlled-checkpoint`. It starts from
the original task/base, without replay, a fixed boundary or filler. Keep the
same model, task, environment and independent acceptance for the A/C pair.

Record maximum actual request input as well as configured window size; the
existing A/C maintenance lifecycle checks remain asymmetric. A post-final-only
summary is not recovery. A task with no boundary is unexercised; a task with
one boundary tests one handoff; repeated boundaries can test continuity across
handoffs. Final feature/preservation scores, boundary timing, subsequent actions,
requests, tokens, elapsed time and cost must all be retained. Incomplete and
unexercised runs stay in the results, without selecting only favorable runs.

This natural protocol measures the existing strategy packages. The controlled
CW18.29 pair remains a separate mechanism comparison and should not be pooled
with these future from-scratch costs or success observations.
