only container execution, Notes, History, and new-context tools. Commands are
forwarded to Pier's isolated `/app`, with bounded timeout and returned output.
No host file tools, project extensions, or skills are exposed to the agent.

hidden test entry point and Docker socket, wrote a durable Note, performed one
