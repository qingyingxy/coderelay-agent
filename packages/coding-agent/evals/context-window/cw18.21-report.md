A did not cover safe-upsert either. The same omission occurred without any

but neither completed the task correctly. Preserve the failed results without
automatic retries or task-specific prompt patches.

distinguish a recorded boundary from actual model execution after it. Any
future repeated comparison should keep requirements and independent grading
fixed and report boundary timing separately; no new paid run is implied.
