## Grading Boundaries

`handoff-replay.ts` checks manual per-requirement annotations: quote presence,
one annotation per scope, evidence availability at that cut, outcome, coverage
and superseding observations. Missing and ambiguous annotations cannot pass.
It does not infer meaning from keywords, judge arbitrary prose, detect all
contradictions, or automatically derive test coverage from source code. Future
model-authored outputs still require semantic review. Annotation accuracy is
part of the evaluation evidence, not an independent guarantee.

Free controls verify:

- Deleting a cited sentence invalidates its stale annotation.
- Keeping "safe upsert" while claiming verification from the full suite fails.
- Failed, nonexistent and future evidence cannot establish verification.
- A single targeted checkpoint pass leaves unrelated requirements pending.
- Explicit user cancellation resolves only its specified scope and does not
  count as verification; retaining the obsolete blocker fails.
- A later targeted failure supersedes an older passing result.
- A later corrected brief cannot erase an earlier recorded omission.

Synthetic targeted evidence and user cancellation are clearly named
`synthetic-*` in the controls. They are not represented as events that occurred
in CW18.14. No structured claim/status fields were added to production Snapshot,
Notes, Seed or tools. No submission gate, merger or routing policy was added.
