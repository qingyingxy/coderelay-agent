## Results

| Scenario | Result | Main evidence |
|---|---:|---|
| Multi-window lineage | Pass | Two hard cuts produced indexes 1 and 2; the latest seed alone was active; old entries remained queryable |
| Resume from JSONL | Pass | The same Session JSONL restored the latest seed and post-boundary messages without replaying the pre-boundary secret |
| Fork, rollback, branch isolation | Pass | Sibling window lineages diverged; History excluded sibling data; rollback removed both futures; fork copied one path |
| Attempt repair recovery | Pass | Failed Verification created a Repair Task; Snapshot restore interrupted the uncertain Attempt and queued an explicit recovery Attempt |
| Overflow hard-cut retry | Pass | The provider error was persisted before one overflow boundary; exactly one retry ran from the new seed and completed |

## Invariants Checked

- Two consecutive hard cuts advance one lineage while retaining all original Session entries.
- Notes and History preserve an exact value across two window boundaries.
- Resume reconstructs active context from persisted boundary data and does not regenerate the seed.
- History is restricted to the active branch for both the original Session and a forked Session JSONL.
- Rollback derives active context and lineage from the selected ancestor rather than stale runtime state.
- Repair recovery preserves the failed Verification and links the new Attempt to the interrupted Attempt.
- Overflow recovery persists the error, excludes it from retry context, and retries at most once in the scenario.

## Scope And Decision

This evaluation exercises real Session JSONL persistence, context reconstruction, Workflow events and Snapshot recovery, but uses scripted model responses. It proves deterministic lifecycle behavior; it does not measure whether a real model can complete a coding task across multiple hard cuts or decide when and how to use Notes and History.

Keep `summary` as the default. CW.17.4 must run a small, strictly serial real-model coding evaluation across at least two hard cuts and a process-level resume before CW.18 considers a default-mode change.
