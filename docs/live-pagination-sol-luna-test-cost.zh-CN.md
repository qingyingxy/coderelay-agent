# 直播分页：sol 直接执行与 sol 规划 + luna 执行

## 结论

按用户确认的“共同测试全部通过即完成”标准，本次单任务对比中：

- sol xhigh 直接执行首次通过测试前花费 **$1.41558480**，首轮通过，无修复。
- sol xhigh 规划 + luna max 执行首次通过测试前花费 **$0.69144308**，包含首次失败、一次审查和一次 sol xhigh 修复。
- 候选方案在这个完成口径下少花 **$0.72414172，约 51.15%**。

这不是原“测试 + 审查均通过”门槛下的同质量成功交付比较。sol 后续审查通过；luna 的后续审查仍指出两处已核实的功能回归。旧报告的失败判定没有被修改。

## 对齐条件

| 项目 | 两组共同条件 |
| --- | --- |
| 初始代码 | 132 个文件哈希一致，不包含已完成实现或审查答案 |
| 测试 | 6 个分页后端测试、59 个原有后端测试、5 个浏览器场景，文件内容一致 |
| 权限 | 允许读取测试和配置，只允许写直播工具相关业务源码；测试、配置、依赖、无关项目禁止写入 |
| 修复 | 最多一次 sol xhigh 修复，测试失败时沿用先审查后修复的流程 |
| 审查 | sol xhigh 只读执行；测试通过后的意见单独记录，不触发额外修复 |
| 停止 | 30 分钟无进展或 12 次重复结果的既有看门狗；无短 Worker 时限、无 $2 费用上限 |
| 上下文 | 按需切窗，不强制触发；两次实际运行均未切窗 |
| 计价 | 冻结配置价格乘接口返回用量，是模型费用估算，不是供应商账单 |

sol 的价格、模型配置与旧候选一致：每百万 token 输入 $4、输出 $20、缓存读取 $0.4。luna 对应为 $0.2、$1.2、$0.02。

两组完成时点之前的已保存响应均有有效用量，检查未发现缺口。luna 的全部实际支出仍未核清，因此不计算“含全部审查的最终账单节省比例”。原先 luna max 档位探测另花 $0.00019280，属于准备费用，本表未将它混入任务阶段。

| --- | --- | --- |
| 首轮测试 | 6/6、59/59、5/5 | 5/6、59/59、5/5 |
| 一次修复后 | 不需要 | 6/6、59/59、5/5 |

| 总运行时长，含审查 | 约 16 分 46 秒 | 约 27 分 51 秒 |

luna 的首轮失败是误删 `_authorized`，由 sol 修复。剩余两处问题是：状态版本变化后没有重新拉取当前队列页，以及直接进入互动数据页时免费资格数据没有加载。固定的五个浏览器场景没有覆盖这两条路径；这些意见作为质量结果保留，没有追加付费修复。

sol 共 21 次执行请求、1 次审查请求，实发档位均为 xhigh。luna 的原运行使用 sol xhigh 规划、luna max 执行、sol xhigh 修复和审查，详情见原候选报告。
