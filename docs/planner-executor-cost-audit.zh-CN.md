目标是在相同任务和验收标准下，比较强模型直接执行与强模型规划、快速模型执行、按需切窗的完整交付成本。

## 核算口径

每次运行成本 = 主会话费用 + 所有独立子 Agent 费用 + 独立审查会话费用。
覆盖首次执行、失败尝试、修复和复审。修复记录中的 cumulativeEstimatedCost 是前次与本次之和，不再次加入账本。
以会话/Agent 标识去重；不再叠加 Workflow、Task、Attempt 的汇总 usage。

getSessionStats 汇总全部会话条目中的 assistant usage、携带 usage 的工具结果及摘要；RPC 子 Agent 从该统计取得费用。
因此已记录的上下文维护模型调用包含在各阶段费用中。切窗工具本身不发起模型调用，但交接文本生成、后续窗口读取交接、历史回查后的回答仍消耗模型 token。
不能把 hardCuts.modelCallTokens=0 理解为切窗相关成本为零，也不能将摘要费用再加到会话总额上。
seed/history 的字节数除以 4 是估算 token，不是可直接按单价追加的账单 token；缓存和重复读取也会影响实际费用。

以下是本地记录费率下的估算美元金额，不是供应商账单。未覆盖本对话人工定位所用模型费用、人工时间、测试机器开销，以及未记录 usage 的失败请求。
对有报告的运行，已逐一检查主会话和子 Agent 加总与报告一致；这不等于已向供应商对账。
