# 历史会话成本评测候选筛选

日期：2026-09-10。此文是选题结果，不是新增付费评测结果。

后续状态：三个候选已完成离线正反验证及输入冻结，见 [离线验收报告](conversation-cost-matrix-offline-preflight.zh-CN.md)。下方准备情况保留选题时的记录。

## 目标与覆盖范围

比较 sol 直接执行、sol 规划 + luna 执行、sol 规划 + terra 执行完成同一真实任务的完整费用。费用应包含规划、执行、切窗维护、审查、失败尝试和有限修复；未交付不能算成功交付省钱。

检索了应用最近 50 个未归档会话、211 个归档会话，并补查本地会话索引。索引共 812 条，其中 346 条为子 Agent，466 条为非子 Agent 会话。覆盖指目录筛选及候选内容核对，不代表逐字读完 466 个会话，也不包含本机未同步的其他设备或 ChatGPT 历史。长标题和长消息存在截断，不能据此认定其他会话绝无合适任务。

补查覆盖直播工具、Unity 游戏、Godot、JobFlow、Memory-RAG、Code Agent Lab、TripStar、论文与压缩实验等项目。以下来源使用真实会话标题和 ID；任务范围是从会话中截取的独立需求，不等于重做整个会话。

Memory-RAG 的真实授权包含“最重要的是组织和权限之类的”及后续“可以，你帮我先做一下吧”。已读取现有权限测试，涉及令牌验证、部门/项目访问、私有资料检索与缓存隔离、成员管理、审计及评测归属。现有测试不能证明前端和 PostgreSQL 路径均完成验收；正式入选前须根据原需求冻结范围，不额外加入安全加固需求。

三个候选不是三个已准备好的付费任务。建议先离线核对基线和共同验收，再冻结最终名单。

## 备选与暂不优先项

- 小红书礼物及评论采集：来自“检查直播礼物读取 (2)”（01a02768-25ba-7ae2-8135-c548ca027bcc）。用户明确反馈人气票未计入、部分评论漏读、表情读取不到；独立修复 d88c902 可查。适合做 DOM/消息重放，但必须先核实样本与浏览器行为验收，不能只凭后端测试或源码字符串检查判定成功。
- Godot 装备掉落与拾取：来自“实现装备掉落与手动拾取”（019eee73-24aa-7453-a3eb-c1d274f8dd4b）。初始范围为装备概率、裂隙手动拾取、其他自动拾取和 Tab 装备面板，不含后续数值和特效扩展。独立提交 19b1da1 可查；大量变更是资源和导入文件。适合长期候选，但需准备随机种子、拾取和界面验收，不宜直接付费开跑。
- Code Agent Lab：来自“按顺序推进执行闭环改造”（019e627b-0dfb-7042-bfd6-3b6dc194fc13）和“实现 planner workflow”（019e63ba-6a16-7cb0-b9f7-4435b46afe85）。用户明确要求多文件原子补丁、Repo Map、符号检索和规划回修，题目质量较好；但本地父仓库按该目录查询只找到 b32eea161 整体快照，尚无可确认的功能前基线。不要通过删除最终实现来伪造历史基线。
- Memory-RAG 排序调优：有真实需求，但模型权重、数据与硬件耗时影响较大；本轮优先权限功能，不重跑整个检索研究。
- TripStar“分析项目”：本次核对主要是学习与架构讨论，未确认独立实现需求，暂不入选。
- Unity 战斗、联机同步、视觉音效和训练压缩实验：需要运行环境、交互、服务端或较重实验，验收准备成本更高，暂不优先。不是判定这些任务没有价值。

## 下一步边界

1. 暂停旧 cost-matrix 三任务草案和付费运行，保留已有隔离文件及证据。
2. 只对最终候选准备同一需求、同一基线和同一验收。确认旧代码能暴露目标缺口、参考实现能满足要求；验收不得绑定参考实现写法。
3. 三组只读原需求和允许的项目资料，不得读历史答案、参考补丁或其他组产物。
4. 固定框架、单 Worker、一次修复上限和一致审查规则后再跑。报告交付状态与完整费用，保留失败花费。
5. 长任务候选首先考虑 Memory-RAG 权限功能，但只有实际触发切窗才算切窗证据，不靠填充上下文制造长任务。

本次未调用付费模型，未修改这些业务项目。
