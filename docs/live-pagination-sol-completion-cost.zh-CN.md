## 本次修复与审查

sol 修复只改变两个业务文件：

- `dashboard_runtime.py`：快照内检测 running 变化，在判断 since 是否匹配前推进 revision。
- `desktop/src/App.vue`：互动页主动加载免费资格，按当前视图刷新相应队列，并处理初始化期间已切换视图的情况。

修复为 13 次模型请求、36 次工具调用；独立复审为 4 次请求。思考深度审计均为 xhigh，修复的 13 个回答与请求数、费用求和一致，没有新有效运行的错误回答；Reviewer 用量记录为 4 轮。未发生切窗。

复审仍使用旧冻结 Reviewer 源码和权限规则，输入相对于原始基线的完整修改，并附实际共同验收结果，不只审两个小修复。最终无必须修复项、建议项或待确认项。Reviewer 已记录 `sessionReleasedAt`，运行进程正常退出，结束后只读进程检查未发现引用本次目录的 node/python/chrome 进程。

## 对照边界

- 这是**已有运行经人工发现漏检后恢复修复的成本比较**，不是两组重新从头执行的全自动配对试验。
- 原 sol 审查漏检事实与原始报告保留。宿主把离线证实的问题传入剩余的一次修复，没有新增一次付费首审；该记录明确标为 host diagnosis，不冒充模型审查结果。
- 候选组复用了之前通过的同范围模型审查，本次只用新增共同测试离线复验，没有追加付费复审。两组审查规则相同，不代表审查输入和覆盖过程逐字相同。
- 未使用刚修正的 Planner 重新规划，因此本结果不能证明新 Planner 的成本收益。
- 候选费用对应选定的 2026-09-11 复测与恢复记录，包含它自己的全部规划、执行、一次修复及两次审查。更早失败候选轮次已记录的 $1.13629668 及其未知用量仍在旧报告，不合并为本轮单次运行成本，也不能从项目全部试验开销中删除。
- 本地验收无模型 API 费用；人工诊断时间、本地算力和当前协作会话费用不在实验模型用量统计内。
